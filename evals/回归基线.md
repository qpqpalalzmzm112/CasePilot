# CasePilot 回归基线（真实 PRD 实测数据）

> 本文固化真实 PRD 横向泛化实测的迭代证据与展示素材（迭代 9 / UP-4 入库）。
> 数据来自 3 个领域真实形态 PRD（充电桩物联网 / 金融转账 / 登录）与单文档四轮迭代实测，
> 供回归对照、面试讲解与效果展示复用。全部口径可由 `tests/` 回归测试复现（离线确定性）。

## 3. 跨域泛化实测（充电桩 / 转账 / 登录，同引擎零改动）

| 指标 | 充电桩物联网 | 金融转账 | 登录 |
| --- | --- | --- | --- |
| 模糊词命中 | 0 | 0 | 0 |
| 领域陷阱命中 | 状态机非法流转 | 舍入 / 幂等 / 并发串行扣减 / 冲正 | 状态机 / 幂等 |
| 限流降级寄生幻觉 | 1 | 0 | 1 |
| 注水条目（模板垃圾） | 2 | 16 | 4 |

核心引擎跨域无退化（状态机非法流转、金额四档边界、幂等、并发串行扣减、冲正规则都接住了），
暴露的两块硬伤已在迭代 9 根治：

1. **自动补齐 = 数量注水**（转账 50 条里 16 条 / 32% 是模板垃圾，8 个条目只拿到
   「系统接受有效输入并处理成功」同义反复）→ **UP-1 废除模板填塞**：补不出具体用例
   就如实登记「未覆盖清单 + 具体设计建议」，覆盖率如实计算（允许 <100%），禁止凑数。
2. **限流降级寄生幻觉**（充电桩用例「12 万台设备触发限流降级」，PRD 只定义 10 万台
   能力目标）→ **UP-2 NFR 寄生幻觉专防**：性能 / 容量条款只产「目标规模下满足判定
   标准」用例，禁止发明超容行为；LLM 模式衍生用例经溯源判定 [假设] 后在关键词列标注
   「场景法,假设」（[假设] 标签首次进入生成产物）。

## 4. 质量门禁收敛时间线

| 里程碑 | 迭代 | 动作 |
| --- | --- | --- |
| 模糊词清零 | v3 | 「或 / 可能 / 视情况」预期禁令（mock 模板 + LLM 门禁 + judge 扣分） |
| 规则改写修复 | v3 | 「锁定 30 分钟 → 30 秒」类改写按数字断言拦截（±1 推导豁免） |
| 编造测量值修复 | v4 | 测量值预言禁令：性能预期只允许判定标准形态（≤2s / ≥100 QPS） |
| FR 硬门禁 | v4 | 需求编号逐字对账 + 覆盖率核对表（PRD 条款 → 用例编号映射） |
| 注水废除 + 假设标注 | 迭代 9 | 模板填塞废除（未覆盖清单 + 具体设计建议 + 零遗漏登记）、[假设] 标注进产物、弱断言禁令、多阈值边界完整性 |

## 5. 结论：流程强制 > 措辞优化

FR 对账从「提示词叮嘱 LLM 记得覆盖需求」到「DoD 硬门禁（零遗漏登记 + 覆盖率如实）」，
一轮见效：需求召回率 ~72% → ~95%，且不再靠模板条目凑覆盖率。
判定标准类问题（模糊词 / 测量值预言 / 弱断言 / 同义反复）全部走同一治理模式：
**词表唯一事实来源 → mock 模板不产出 → LLM 命中即校验失败回灌重试 → 耗尽丢弃告警 → judge 扣分点名**。
