# 登录安全与性能需求文档

## 背景与目标

登录模块需同时满足安全合规要求与性能指标：拦截 SQL 注入、越权访问等攻击行为，敏感信息展示需脱敏；核心登录接口在高并发压力场景下保持稳定可用。本文档聚焦安全要求与性能指标两类需求。

## 安全要求

- 防 SQL 注入拦截
- 敏感信息脱敏展示
- 越权访问拦截
- 会话令牌防篡改
- 登录失败 5 次锁定账号 30 分钟
- 短信验证码 60 秒内有效

## 性能指标

- 接口响应时间 ≤2 秒
- 支持 50 并发用户同时登录
- 登录接口吞吐量 ≥100 QPS
- 压力场景持续 30 分钟系统稳定
- 页面加载耗时 ≤3 秒

## 主流程

1. 打开登录页面
2. 输入账号、密码与短信验证码
3. 提交登录请求
4. 通过安全校验后跳转首页

## 异常与边界说明

- 注入特征被拦截时提示「请求非法」
- 并发超过 50 时排队并提示「当前排队中，请稍后重试」
