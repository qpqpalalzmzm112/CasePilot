# 简历项目条目与求职素材

本页把 CasePilot 的实测成果整理成可直接写进简历、可直接说出口的素材。所有数字都来自本仓库实测（复现命令见 [README](../README.md)），面试前可以当场跑一遍。

## 一、简历一行式项目表述（二选一）

### 版本 A：偏测试开发

> **CasePilot（Python）**：AI 生成测试用例直出禅道 Excel，332 测试覆盖 96%，3 样例评测 100 分

### 版本 B：偏工程质量

> **CasePilot（Python）**：LLM 双模式生成+4 维评测+质量自评，332 测试覆盖 96%，好坏用例评分差 2.9

使用建议：投「软件测试 / 测试开发实习」用 A，突出从文档到禅道的完整测试工作流；投更看重工程素养的岗位用 B，突出双模式、评测体系与质量自评。两条各含 4 个量化数字，放在「项目经历」首行，下面接 STAR 描述。

## 二、STAR 项目描述（约 245 字，150~250 字内）

> 「情境」中文需求拆用例靠人工，方法论对错看不出来，禅道导入表常因格式出错；「任务」做一个开源 CLI，打通文档到禅道全流程；「行动」用 Python/Typer/pydantic 搭 CLI，按等价类、边界值、场景法、判定表生成标注用例，LLM 网关三级降级、无 key 离线可跑，自建 4 维评测与 golden 基准集、LLM-as-a-Judge 自评质量；「结果」5 轮迭代 332 项测试覆盖率 96.13%，3 样例生成 27/30/25 条用例、评测 100.0，好坏用例集分差 2.9，一键导出禅道 Excel 等三格式。

四要素齐全：情境（人工拆用例的痛点）→ 任务（开源 CLI 自动化）→ 行动（CLI 与结构校验 / 方法论生成 / 三级降级 / 评测体系）→ 结果（全部量化数字收尾）。

## 四、使用提醒

- 数字只能按本表原样说，不要四舍五入美化：96.13% 说 96.13% 或 96% 都可以，别说 97%。
- 每个数字都有复现命令背书（`pytest --cov=casepilot --cov=evals`、`casepilot eval -i examples/prd_login.md`、`casepilot judge output/prd_login_cases.xlsx`），面试官要求现场验证时照着敲。
- 面试问答配合 [interview_qa.md](interview_qa.md) 的锚点式话术一起练。
