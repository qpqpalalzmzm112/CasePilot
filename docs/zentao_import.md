# 禅道导入操作指南

本文档说明如何把 CasePilot 导出的禅道格式 Excel 用例表导入禅道（Zentao），并附人工验证清单。
导出命令：

```bash
casepilot gen -i <需求文档或接口文档>            # 默认 --emit xlsx
```

导出成功后 CLI 会自动执行**导入前校验**并输出中文校验报告，例如：

```text
禅道导入前校验：output\prd_login_cases.xlsx
  - Sheet「用例」存在，表头 8 列与官方导入模板一致
  - 数据行 27 行，必填字段完整
  - 优先级取值全部合法（1/2/3/4）
校验结论：可导入
```

> 只有校验结论为「可导入」的文件才建议执行导入；「不可导入」会列出具体错误字段与行号，修正后重新导出。

## 一、文件格式要求（禅道官方用例导入模板）

- 文件类型：`.xlsx`（Excel 2007+）
- Sheet 名：`用例`
- 第一行为表头，列名与顺序**固定**如下：

| 列序 | 列名 | 说明 |
| --- | --- | --- |
| 1 | 所属模块 | `父模块/子模块` 路径，导入时自动创建模块层级 |
| 2 | 用例标题 | 必填，非空 |
| 3 | 前置条件 | 建议填写 |
| 4 | 步骤 | 必填，多步骤用换行 `1. …\n2. …` |
| 5 | 预期结果 | 必填，非空 |
| 6 | 优先级 | 必填，数字 `1/2/3/4`（对应 P0/P1/P2/P3） |
| 7 | 用例类型 | `功能` / `接口` / `异常` / `边界`（禅道中可自定义映射） |
| 8 | 关键词 | 测试方法论：`等价类` / `边界值` / `场景法` / `判定表`（显式方法论标注） |

## 二、导入步骤（禅道 Web 端）

1. 登录禅道，进入目标**项目**。
2. 顶部导航「测试 → 用例」，切换到需要导入用例的模块（建议先建好一级模块）。
3. 点击右侧「**导入**」按钮，选择「从 Excel 导入」。
4. 选择 CasePilot 导出的 `.xlsx` 文件，字段映射保持默认（表头与官方模板一致时自动映射）。
5. 确认导入预览无误后提交；导入完成后记录成功 / 失败条数。
6. 若用例类型提示无法识别：进入「测试 → 用例 → 用例类型」自定义 `接口` / `边界` 等类型后重新导入。

## 三、人工验证清单

导入完成后，逐项人工核对（建议在验收记录中打勾）：

- [ ] 导入条数与 CLI 报告的「数据行 N 行」一致，无静默丢弃
- [ ] 模块树正确：`父模块/子模块` 路径被还原为禅道模块层级
- [ ] 抽查 3 条用例：标题、前置条件、步骤、预期结果与导出文件逐字一致（多步骤换行被保留）
- [ ] 优先级抽查：`1` 显示为最高优先级（P0），`4` 显示为最低（P3）
- [ ] 用例类型列显示为 `功能 / 接口 / 异常 / 边界`，无法识别时已建立自定义类型映射
- [ ] 关键词列保留方法论标注（`等价类 / 边界值 / 场景法 / 判定表`），可用于禅道筛选
- [ ] 边界值用例的预期结果含具体数值与两侧相邻值（如「输入 5 时被接受…4 和 6 …」）
- [ ] 禅道内执行一次「用例列表 → 导出」回导对比，无字段错位

## 四、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 提示「列名不匹配」 | 文件被手工改过列名 / 列序；重新用 `casepilot gen` 导出，勿改表头 |
| 优先级显示异常 | 优先级列必须是数字 1-4；查看校验报告中的「优先级非法取值」错误 |
| 用例类型为空 | 禅道未建立自定义类型映射，先在禅道建 `接口` / `边界` 类型 |
| 中文乱码 | 确认文件为 UTF-8 环境下导出的 `.xlsx`（CasePilot 默认 UTF-8） |
| 导入条数少于导出条数 | 检查是否有标题为空的行；校验器会报「禅道导入必填」错误 |

## 五、校验器错误速查

导入前校验器（导出 xlsx 时自动执行）可能输出的错误与含义：

| 错误信息 | 含义 |
| --- | --- |
| `第 N 列列名错误：期望「x」，实际「y」` | 表头被改动，与官方模板不一致 |
| `第 N 行「字段」为空，禅道导入必填` | 必填列缺失内容 |
| `第 N 行「优先级」非法取值「v」` | 优先级不在 1/2/3/4 内 |
| `缺少「用例」工作表` | Sheet 名不是「用例」 |
| `用例数据为空，无可导入内容` | 只有表头没有数据行 |
| `文件不存在` / `无法打开 Excel 文件` | 路径错误或文件损坏 |

校验器对「用例类型 / 关键词」取值超出常用枚举的情况仅给出**警告**（禅道支持自定义映射），不阻断导入。
